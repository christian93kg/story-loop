# Card — accent-via-syntax
Applies whenever two or more characters speak the same base language with different origin, class, or education — render the difference through syntax and diction, never phonetic spelling.

## Tests
- Unattributed calm-register line per speaker: can a reader assign it correctly ≥9/10 times on diction + syntax alone?
- Count subordinate clauses: blunt/L2 speaker trends toward zero (parataxis, asyndeton); learned speaker toward two-plus (hypotaxis, periodic sentences).
- Formal speaker phrases requests as indirect conditional, zero contractions; blunt speaker as bare contracted imperative. Identical phrasing = fail.
- A false friend/cognate trap must map to a real transfer error (e.g. "library" for bookshop), otherwise grammatical — not just a random wrong word.
- A stacked construction ("have"-for-age, dative-sensation, "that"-for-infinitive) must reproduce a *specific* source-language structure, not generic broken English.
- Archaic/formal grammar (thou/thee, subjunctive) must be *correct* — accurate inflection, correct intimacy/deference register. An inflection error reads as authorial mistake, not voice, unless dramatized as a rare deliberate slip.
- Stress-degradation follows a fixed order (function words/contractions → complex tenses → word order → native-language lexis/calques), not random error density.
- Calm line vs. its stressed counterpart: can you name the exact feature(s) that changed? If the delta is unrelated errors, redo it.
- No single baseline (non-stressed) line stacks more than ~2 transfer features — more tips into caricature.
- A borrowed/untranslated word does work (status, emotion, an untranslatable concept) rather than decorating for flavor.

## Kill list
- Phonetic respelling / eye-dialect of any kind ("wimmin," "'ello," dropped-letter apostrophes for sound) — contractions like "don't" are fine, spelling changes are not.
- Random or inconsistent error density standing in for accent (no directional logic).
- A glossary or authorial gloss explaining the invented/foreign terms — let context clarify.
- Negative concord ("didn't see nothing") used as the *sole* marker of a non-native origin — it reads as native vernacular first; pair it with an unambiguous marker or reassign it.
- Archaic thou/you or subjunctive used inaccurately — a "wrong" archaism breaks the illusion instead of building it.
- More than ~2 transfer features stacked in one baseline (non-stressed) line.
- Identical rate/kind of transfer feature across two speakers meant to be distinguishable (collapses register into generic "accent").
- Borrowed foreign words inserted purely as decorative flavor with an available, equally natural English equivalent.

## Micro-examples
Diction split (same L1, opposite register), same intention:
- Before (flat): "I don't need help. It doesn't matter."
- After, formal speaker: "I require no assistance; the matter is of no consequence."
- After, blunt speaker: "Don't need help. Doesn't matter."

Archaic grammar, correct vs. broken:
- Before (flat): "You know what you did."
- After (accurate): "Thou knowest what thou hast done." (correct -est/hast inflection; thou chosen deliberately for intimacy/contempt)
- Fail version: "Thou knows what you done." (mixed pronouns, wrong inflection — reads as error, not voice)

### Digest — accent-via-syntax
When: two or more speakers share a base language across origin, class, or education lines.
- A reader can assign an unattributed calm line to its speaker ≥9/10 on diction and syntax alone.
- Blunt/L2 speaker trends to zero subordinate clauses, learned speaker to two-plus; requests split indirect-conditional vs. bare imperative.
- Transfer features reproduce a specific source-language structure; stress-degradation follows the fixed order (function words → tenses → word order → calques).
- Max ~2 transfer features per calm line, each doing work (status, emotion, untranslatable concept); archaic grammar correct or dramatized as a rare slip.
KILL: random error density; authorial glossaries; negative concord as sole L2 marker; identical feature-rates across distinct speakers.
